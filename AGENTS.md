## Project

 This is a connector between evcc and the gcs-platform. gcs-platform (https://github.com/larknafets/gcs-platform; local `../gcs-platform`) is a free charging platform. A Home Assistant Add-on wrapping this app lives at https://github.com/larknafets/gcs-ha-addons, subfolder `gcs-connector-evcc` - also accessible locally at `../gcs-ha-addons`.

## Tracker and domain

- Issue tracker: GitHub Issues via `gh` CLI (larknafets/gcs-connector-evcc).
- Domain: single-context, root `GLOSSARY.md` + `docs/adr/`.
